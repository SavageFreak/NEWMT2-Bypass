# NEWMT2 Panel

## 🇬🇧 English

### About

NEWMT2 Panel is a lightweight Windows launcher/panel for NEWMT2, built in C/C++.

It is designed to provide a simple interface for launching and managing the game with minimal setup.

### Features

- Native Windows application
- Built with C/C++
- Simple and lightweight interface
- Game launcher integration
- Local configuration support

### Installation

1. Download the latest `.zip` package.
2. Extract the archive.
3. Keep the included runtime files together.
4. Run `panel.exe`.

## 🇬🇷 Ελληνικά

### Σχετικά

Το NEWMT2 Panel είναι ένα ελαφρύ Windows launcher/panel για το NEWMT2, γραμμένο σε C/C++.

Έχει σχεδιαστεί ώστε να παρέχει ένα απλό interface για την εκκίνηση και τη διαχείριση του παιχνιδιού, με όσο το δυνατόν λιγότερο setup.

### Χαρακτηριστικά

- Native εφαρμογή για Windows
- Γραμμένη σε C/C++
- Απλό και ελαφρύ interface
- Ενσωμάτωση με τον game launcher
- Υποστήριξη τοπικών ρυθμίσεων

### Εγκατάσταση

1. Κατέβασε το τελευταίο `.zip` package.
2. Κάνε extract το archive.
3. Κράτησε μαζί όλα τα runtime αρχεία που περιλαμβάνονται.
4. Τρέξε το `panel.exe`.
